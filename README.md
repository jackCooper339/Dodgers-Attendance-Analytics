# Dodgers Attendance & Marketing Analytics

## Project Overview

Analyzed attendance data from 81 Los Angeles Dodgers home games during the 2012 MLB season using SQL and Tableau to identify trends in fan attendance, promotional effectiveness, and scheduling.

**Objective:** Use data-driven insights to support sports marketing decisions and ticket sales strategies.

## Tools & Skills

- **SQL (SQLite):** Data querying, aggregation, CASE statements, and comparative analysis
- **Tableau:** Data visualization and interactive dashboard development
- **DB Browser for SQLite:** Database management and SQL execution
- **GitHub:** Project documentation and portfolio management

## Business Questions

1. Which opponents attracted the highest average attendance?
2. Which days of the week had the highest attendance?
3. Did promotional games have higher attendance?
4. Which promotional giveaway types attracted the most fans?
5. How did attendance change throughout the season?
6. Did weekend games attract more fans than weekday games?

## Key Findings

- **Promotions:** Promotional games averaged 45,866 attendees, compared with 38,201 for non-promotional games, approximately 20.1% higher.
- **Giveaways:** Bobblehead promotions had the highest average attendance at 53,145 fans.
- **Opponents:** Games against the Angels averaged 49,777 attendees, the highest among opponents.
- **Scheduling:** Tuesday games averaged 47,741 attendees, the highest of any day of the week.
- **Seasonality:** June recorded the highest monthly average attendance at 47,940.
- **Weekends:** Weekend games averaged 42,671 attendees versus 40,269 for weekday games.

## Business Recommendations

- Test targeted promotions on lower-attendance game dates to potentially increase ticket demand.
- Consider opponent popularity when planning marketing campaigns and ticketing strategies.
- Evaluate promotional giveaways to identify which offerings are most strongly associated with fan turnout.

## Limitations

The analysis uses observational data from one MLB season. Attendance differences show associations, not necessarily causation. Opponent popularity, scheduling, and other factors may influence the results.
